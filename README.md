# 🚀 Projeto .NET Core & C# na Prática

Bem-vindo(a)! 👋  
Este é um **projeto open-source** criado com o objetivo de **aprender, evoluir e construir software de verdade** usando **.NET Core e C#**, aplicando boas práticas desde o início.

A ideia aqui não é só código — é **troca de conhecimento**, **evolução contínua** e **aprendizado coletivo**.

---

## 🎯 Objetivo do Projeto

Este projeto foi criado para:

- Ajudar **desenvolvedores iniciantes e intermediários** em .NET
- Construir uma aplicação **realista**, como se fosse de produção
- Aplicar conceitos modernos de arquitetura e design
- Evoluir o código continuamente, versão após versão
- Incentivar contribuições e revisões de código

👉 Tudo isso de forma **aberta**, colaborativa e didática.

---

## 🧠 O que você vai aprender aqui

- ✅ .NET Core com C#
- ✅ APIs REST
- ✅ Clean Architecture
- ✅ DDD (Domain-Driven Design)
- ✅ Boas práticas de código
- ✅ Organização de projetos
- ✅ Evolução de versões
- ✅ Análise e refatoração de código
- ✅ Padrões usados no dia a dia profissional

---

## 🏗️ Arquitetura

Este projeto segue os princípios de:

- **Clean Architecture**
- **Separação de responsabilidades**
- **Domínio desacoplado**
- **Facilidade para testes**
- **Escalabilidade e manutenção**

A estrutura foi pensada para ser **simples de entender**, mesmo para quem está começando.

- Quer aprender fazendo

### Como contribuir:
1. Faça um **fork** do projeto
2. Crie uma branch
3. Implemente melhorias, correções ou novas funcionalidades
4. Abra um **Pull Request**
5. Vamos analisar e evoluir juntos 🚀

Issues para iniciantes serão marcadas como **`good first issue`**.
